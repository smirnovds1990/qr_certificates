# qr_certificates

Необходимо разработать приложение, доступное по прямой ссылке, которое будет отправляться клиентам для оформления и оплаты электронного сертификата.

1) Выбор номинала и оформление:
Клиенту предлагается выбрать номинал сертификата:
- Номиналы от 1 000 до 15 000 ₽, с шагом в 1 000 ₽.
- При выборе номинала — обязательно поле для ввода адреса электронной почты.
- На указанный email будет отправлен электронный сертификат с QR-кодом.
  
2) Интеграция с платёжной системой:
- Оплата должна происходить напрямую через платёжную систему ЮKassa (ЮKassa API).
-После успешной оплаты:
Сертификат автоматически генерируется и отправляется клиенту на указанную почту.

3) Хранение и доступ к сертификатам.
Административная панель должна включать:
- Список всех проданных сертификатов
- Указанные клиентами email-адреса
- Возможность повторной отправки сертификата на тот же email по запросу (например, если клиент потерял письмо)

4) Использование и погашение сертификата.
Менеджер на точке может:
- Отсканировать QR-код с устройства клиента (через камеру смартфона)
- После сканирования система должна списать сертификат и деактивировать его
- При повторном сканировании использованного сертификата должна выводиться ошибка “Сертификат уже использован”
