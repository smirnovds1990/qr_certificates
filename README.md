# qr_certificates

Нужно разработать приложение (имеется ввиду не мобильное, просто веб версия) с доступом по ссылке для электронных сертификатов. 

Кратко функционал:
 - одноразовый куар код для каждого клиента, при сканировании телефоном сертификат списывается. 
- привязка платёжной системы компании (юкасса)  для оплаты
- заранее заданные номиналы сертификатов 
- возможность отправки сертификата в подарок по указанной почте 
- отчетность по количеству и номиналу проданных сертификатов

Стоит учесть, что должна быть еще админка, но простенькая:
1. Номиналы (заведение/удаление) 
2. История продажи (оплаты и деактивации сертификата)
